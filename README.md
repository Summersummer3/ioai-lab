# IOAI Lab

面向学过 Python、刚开始学习数据处理与机器学习的学习者的本地练习网页。

- 训练首页：按周导航、查看进度、继续下一道题。
- Week 1：NumPy、Pandas、Matplotlib 与数据分析综合练习。
- Week 2：数据划分、KNN、评价指标、标准化流水线、交叉验证和独立分类项目。
- 两周共 42 道练习，配有逐句笔记、提示、参考解法与自动检查。
- 本地运行 Python，显示图表，可下载生成的 CSV 文件。
- 代码与学习进度保存在本机，支持导出和恢复备份。

## 启动

需要 Python 3.11 或更新版本，首次安装依赖需要联网，准备好后可以离线练习。

1. 下载并完整解压仓库，或使用 Git 克隆。
2. Windows 双击 `启动练习.bat`；macOS 双击 `启动练习.command`。
3. 启动器创建独立环境、安装依赖，并打开 http://127.0.0.1:8765/ 。请保留启动窗口，按 Ctrl+C 停止。

也可以运行 `python bootstrap.py`（部分系统的命令为 `python3`）。详细安装、迁移进度和常见问题见 [使用说明](使用说明.md)。

## 运行方式

Python 标准库提供本地服务，前端使用 HTML/CSS/JavaScript。每次代码运行使用独立 Python 进程，支持 NumPy、Pandas、Matplotlib 和 scikit-learn。

练习代码直接在本机执行，临时目录不是安全沙箱。服务只监听本机地址；请仅运行自己理解并信任的代码。本仓库不包含个人学习记录或虚拟环境。

本项目是个人备赛练习工具，并非 IOAI 官方平台。
