# IOAI Lab

面向学过 Python、刚开始学习数据处理与机器学习的学习者的本地练习网页。

- 训练首页：按周导航、查看进度、继续下一道题。
- Week 1：NumPy、Pandas、Matplotlib 与数据分析综合练习。
- Week 2：数据划分、KNN、评价指标、标准化流水线、交叉验证和独立分类项目。
- Week 3：模型原理、手算与迁移练习，覆盖 KNN、决策树、回归、概率与阈值。
- 三周共 63 道练习，配有逐句笔记、提示、参考解法与自动检查。
- 编辑器支持 Ctrl+/（Windows）或 ⌘+/（macOS）切换当前行或选中多行的注释，支持撤销。
- 本地运行 Python，显示图表，可下载生成的 CSV 文件。
- 代码与学习进度保存在本机，支持导出和恢复备份。
- 学习与练习分开保存代码；笔记中的运行按钮会自动补齐该示例需要的准备代码。
- 学习备份包含练习答案、通过记录、示例草稿和阅读位置，可用于换电脑。

## 启动

需要 Python 3.11 或更新版本，首次安装依赖需要联网，准备好后可以离线练习。

1. 下载并完整解压仓库，或使用 Git 克隆。
2. Windows 双击 `启动练习.bat`；macOS 双击 `启动练习.command`。
3. 启动器创建独立环境、安装依赖，并打开 http://127.0.0.1:8765/ 。请保留启动窗口，按 Ctrl+C 停止。

也可以运行 `python bootstrap.py`（部分系统的命令为 `python3`）。详细安装、迁移进度和常见问题见 [使用说明](使用说明.md)。

## 运行方式

Python 标准库提供本地服务，前端使用 HTML/CSS/JavaScript。每次代码运行使用独立 Python 进程，支持 NumPy、Pandas、Matplotlib 和 scikit-learn。

练习代码直接在本机执行，临时目录不是安全沙箱。服务只监听本机地址；请仅运行自己理解并信任的代码。本仓库不包含个人学习记录或虚拟环境。

本项目是个人备赛练习工具，并非 IOAI 官方平台。

## 回归检查

在已安装项目依赖的 Python 环境中运行 `python -m unittest discover -s tests -p 'test_*.py'`，检查笔记示例能否独立运行以及错误行提示。安装了 Node.js 的开发者还可以运行 `node tests/backup.test.cjs`，检查备份导出与恢复；日常学习不需要 Node.js。

## 课程维护

第三周讲义与练习由 `scripts/build_week3.py` 维护，执行 `python scripts/build_week3.py` 重新生成公开课程、检查定义和周索引。示例与练习使用不同数据或目标；函数题用新输入检查。第二周已完成的题号与通过记录保持有效。

升级到三周版本后请重启服务并刷新旧标签页。新服务拒绝旧页面提交进度，避免旧页面覆盖第三周记录；旧学习备份仍可导入。运行 `node tests/editor.test.cjs` 检查注释操作；`node tests/backup.test.cjs` 检查三周备份。
